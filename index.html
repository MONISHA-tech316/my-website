Features

Everything you need
to run a school

From adding students to tracking GPA trends — all the tools built into one clean interface.

📋
Student Records
Add, edit, and delete student profiles with name, roll number, email, department, grade and GPA.
🔍
Smart Search
Instantly search across all fields — name, roll number, email or department — in real time.
📊
GPA Tracking
Visual GPA progress bars color-coded green, amber, and red so you can spot struggling students instantly.
🏷️
Grade Badges
Color-coded A, B, C grade badges and active/inactive status indicators for every student.
📈
Dashboard Stats
Live counters for total students, active count, average GPA, and top performer — always up to date.
🔽
Sort & Filter
Sort by any column, filter by department, and instantly narrow down to exactly who you need.
How it works

Up and running in minutes

No setup, no database, no server. Just open and use.

1
Download the file
Get the single index.html file — no installation needed.
2
Open in browser
Double-click the file or use VS Code Live Server to open it instantly in your browser.
3
Add your students
Click "+ Add Student", fill in the details and your records are live immediately.
4
Deploy anywhere
Upload to Netlify, GitHub Pages, or tiiny.host and share the link with anyone.
